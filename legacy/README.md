# Versions historiques de neuromuse

Ce dossier conserve des états anciens de neuromuse, à titre de
référence. Ils sont archivés tels quels et ne sont pas maintenus :
ils ne sont pas destinés à être corrigés ni chargés avec la version
actuelle (`src/`).

| Version | Date | Environnement | Description |
|---|---|---|---|
| [neuromuse-2001-concert](neuromuse-2001-concert/) | 7 juin 2001 | MCL, Mac OS 9, MidiShare | Version utilisée pour *L'Écarlate* (Ircam), contenant `ANN 1.4.lisp`, noyau du futur neuromuse, et connecté au projet [LabanOnLisp](https://github.com/FredVoisin/LabanOnLisp) |
| [neuromuse-2003-openmusic](neuromuse-2003-openmusic/) | 26 sept. 2003 | OpenMusic 4.7, MCL 5 | neurOMuse v1, bibliothèque OpenMusic (CIRM) |

D'autres versions antérieures (1999, 2000) pourront être ajoutées
ultérieurement.

Remerciements à Florian Iochem pour son inspiration.
